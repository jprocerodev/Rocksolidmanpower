# Rock Solid Careers Philippines

Website for Rock Solid Careers Philippines, built with React, TypeScript, Vite, and Tailwind CSS.

## Local development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:8080`.

## Production build

```sh
npm run build
```

The production-ready files are generated in `dist/`.

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase
